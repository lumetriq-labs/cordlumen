# 学習データの観点

ポスト検出モデル（1段目 `post_kp`、2段目 `post_refine`）の学習データを、どういう観点で作っているかをまとめた資料です。
合成データの生成スクリプトと学習スクリプトはリポジトリ外（`~/cordlumen-data/`）にあります。生成の内容を変えたら、この資料も合わせて更新します。

## 1. モデルが学ぶもの

- 1枚の写真から、左右のポストの上端と根元の4点（左上・左根元・右上・右根元）を出す。
- 上端の誤差はそのまま高さの誤差になる。ポストを短く見誤ると、ネットは高く判定される。
- 実写（2026-11-14 撮影の4枚）では上端8点がすべて外れた。外れ方は次の3通り。
  - ネットの内側にある黒い縁に打った（4点）。
  - 地面と壁の境界に打った（3点）。
  - ロープの結び目に打った（1点）。

## 2. データの構成

| 種類 | 中身 | 用途 |
|---|---|---|
| 実写 `datasets/labeled` | Wikimedia Commons 41枚（そのうち5枚は検証用に除外） | 1段目・2段目の学習 |
| 実写 `datasets/labeled2` | Wikimedia Commons 17枚 | 学習 |
| 合成 `synth/syn1k/final` | Blender で描画した1000枚 | 学習（run3。実写は5回繰り返して混ぜる） |
| 自分で撮った実写 | IMG_1266/1267、IMG_1278〜1281（手で正解を付けた） | 評価のみ |
| 評価用の合成 | `runs/walltest*`、`runs/postgrad*` など | 評価のみ（学習には使わない） |

素材のライセンス：Poly Haven（HDRI・テクスチャ・3Dモデル）と MPFB/MakeHuman の素材パックは CC0。Wikimedia の写真はそれぞれのライセンスに従い、`labels.json` に作者と出典を記録している。

## 3. 合成データで変えているもの（`gen.py`）

### 照明
- 空と周囲の景色：Poly Haven の HDRI。65% は晴れのもの。向きはランダムに回し、明るさは 0.6〜1.5 倍。
- 太陽光：晴れの HDRI では、太陽の向きに合わせて太陽光を追加する（強さ 1.5〜5 倍、色は少し暖色寄り）。

### 地面・コート
- 種類：ハード、オムニ、クレー、芝。
- 汚れ：細かい粒の質感、すり減ったまだら、ベースライン付近の摩耗、筋、しみ、凹凸。
- 内側のコートを別の色にする（50%）。ラインはかすれる。
- 隣のコート（50%。そのうち40%は両隣）。

### 壁・フェンス
- 金網：灰・緑・黒。支柱あり。高さ 2.5〜5 m。
- 目隠し幕（60%）：濃い緑・深緑・紺・黒、高さ 1.2〜2.6 m。
- 幕の汚れ：日焼けのまだら、雨の縦筋、パネルの継ぎ目（60%）、地面から 0.15〜0.6 m の泥はね、しみ。

### ポスト
- 形：丸（80%）または角。半径 3.2〜5 cm。上部は滑車・ドーム・平ら。
- 付属物：根元のスリーブ（60%）、巻き上げ機（75%。そのうちハンドル付き 80%）。
- 質感：55% が銀色の金属。残りは塗装（濃い緑2色・黒・白・紺・赤）。錆や汚れのまだらを重ね、地面近くを暗くする。
- ロープ：ポストに巻いたもの 0〜3 本。

### ネット
- 網の色：黒・濃い緑・紺。上端の白い帯、センターストラップ、上端のコード。
- 両端の縦帯：網と同じ色。
- たるみ・センターの高さずれ：`SLACK=1` のときだけ入れる（syn1k には入っていない）。

### 人・物
- 人：0〜3 人（40% はポストの ±1.5 m 以内）。今はパイプをつないだような人形。
- 人と巻いたロープをポストのすぐ横に置く設定：`DISTRACT=1` のときだけ（syn1k には入っていない）。
- その他の物：木・植え込み・街灯、ベンチ・ごみ箱・かご・バケツ、審判台（30%）、照明柱 0〜4 本、ボール 0〜25 個。

### カメラ
- 標準の配置：ポストの近く 50%、中距離 25%、遠く 25%。高さ 1.0〜2.6 m。
- `CAM=front`：ベースラインやサービスラインの後ろ 5〜13 m から、ほぼ正面を向く（実際の撮り方）。
- 焦点距離（35mm 換算）13〜52 mm。縦構図 25%。傾き ±6°。
- 4点がすべて画面内に入る構図だけを採用する。

### 撮影の劣化（`postfx.py`）
- ぼけ（35%）、手ぶれ（20%）、露出 0.65〜1.35 倍、ガンマ、ホワイトバランス ±10%、周辺減光（35%）、ノイズ（70%）、JPEG 画質 55〜95。

### 正解ラベル
- 4点の画像上の座標と、点ごとの「見えているか」（カメラから点までの間に他の物があれば見えない）。
- 2026-11-14 から、見えない点は1段目の損失計算と2段目の切り抜きから外している（`train.py`、`crops.py`）。それより前のモデル（run3 と night2）は、隠れたポストの位置も正解として学習していた。syn1k では 1000 枚中 74 枚が該当する。

## 4. 実写とのずれ（分かっているもの）

| 観点 | 実写 | 合成（現状） | 状態 |
|---|---|---|---|
| ポストの明るさ | 濃い緑でほぼ黒（L*≈10）。上下で差なし（上−下 −4） | 銀・白・青などが多く明るい（上端 L*≈50）。上が明るく下が暗い（上−下 +15〜25） | 原因を調べた。金属・太陽光・汚れ・ネットを外しても +19 残るので、照明そのものによる差と見ている。ポストの色を暗くする案は未検証 |
| ポストと壁の色の近さ（画像上の ΔE） | 中央値 7.2（1.4〜11.1） | ΔE < 8 の場面は少ない（壁色を合わせた設定でも中央値 12.3） | 画像上で色を合わせる `WALLTEST=match` を作り、80組を描画済み。集計はまだ |
| 人 | 肌色、普通の服（暗い服・柄物を含む） | パイプをつないだ人形。肌色でない | MPFB2 で人物ライブラリを試作中（`make_humans.py`）。暗い服 45%、柄物 35%、単色 20% |
| 撮影位置 | ほぼ全部、コートの後ろから正面 | 正面に近い構図は syn1k の 8.7% | 次の学習データで `CAM=front` を増やす |
| ネット端の縦帯 | まっすぐな黒い枠や帯 | 制御点ごとに ±4 cm ずれて波打ち、ポストに重なる | 未対応 |
| ロープの結び目 | ポストの途中にある | ロープはあるが、結び目はない | 未対応 |

## 5. 評価のしかた

- 上端・根元の誤差は「ポストの長さに対する %」で見る。10% を超えたら失敗。
- 色の近さは、3D の設定値ではなく描画後の画像の上で測る（CIE76 の ΔE、`eval/top_contrast.py`）。設定上は同じ色でも、照明で画像上の色は変わるため。
- 何かの影響を調べるときは、同じ乱数シードで「その条件だけ変えた」組を作り、組ごとに比べる（`WALLTEST`、`POSTDBG`）。
- 実写は自分で撮った写真に手で正解を付け、センターの高さも手計算と比べる（IMG_1279：84.5 cm、IMG_1280：84.9 cm）。
